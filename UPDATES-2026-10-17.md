# ZG ZoneMisions — 2026-10-17

## English — SERVER ONLY

Improves daily mission rotation and fills missing daily slots without discarding progress. Adds /misiones estado to inspect the assigned day, time zone and next reset. New installations default to America/New_York; existing TOML files, including UTC settings, are preserved. Fixes bounded UI scrolling.

Minecraft 1.20.1 / Forge 47.x / Java 17. ZG ZoneCore: required (server). ZG ZoneCrates: required (server). Stop the server/client before replacing JARs, keep only one version per side, and back up the world/configuration.

 Public protected distribution; private sources, obfuscation mappings and production account/configuration files are not included. Java obfuscation is not an absolute anti-decompilation guarantee. Original release checks and isolated protected-server startup are documented separately; graphical client, real multiplayer and full-modpack behavior are not certified by this upload.

## Español — SOLO SERVIDOR

Mejora la rotación diaria y completa espacios libres sin descartar progreso. Añade /misiones estado para consultar fecha, zona horaria y próximo reinicio. Las instalaciones nuevas usan America/New_York; se conservan los TOML existentes, incluido UTC. Corrige el desplazamiento acotado de la interfaz.

Detén ambos lados antes de sustituir los JAR, deja una versión por lado y respalda mundo/configuración. Distribución pública protegida sin fuentes, mapas de ofuscación ni datos privados de producción. Las pruebas locales no certifican cliente gráfico, multijugador real ni modpack completo.
